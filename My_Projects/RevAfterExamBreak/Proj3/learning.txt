4. Why Use createElement Instead of .innerHTML for adding images as links using just JavaScript?

• Safer: It automatically escapes text and URLs, eliminating Cross-Site Scripting (XSS) security risks if any URLs come from user input or external APIs.
• Preserves existing elements: Appending new nodes doesn't destroy or re-render elements (or event listeners) that are already inside newDiv.
• Easier event handling: You have direct references to link and img in JavaScript if you want to immediately attach .addEventListener('click', ...) or .onerror handlers to each image.
